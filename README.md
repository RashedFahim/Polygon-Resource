## 🌱 About the Project

**Polygon Resource** is a modern and responsive agricultural export website developed to establish a professional digital presence for the company.

The platform showcases agricultural products through a clean and user-friendly interface while providing potential customers with information about the company, its products, services, and international trade opportunities.

The website is designed with a strong focus on **modern UI/UX, responsive design, smooth interactions, and easy navigation** across different devices.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/polygon-resource-website.git
```

### 2. Navigate to the Project

```bash
cd polygon-resource-website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:5173
```

---

## 🏗️ Production Build

Create an optimized production build using:

```bash
npm run build
```

The production files will be generated inside:

```text
dist/
```

Preview the production build locally with:

```bash
npm run preview
```
